ROS 2 Unitree-roboteissa: nollasta ensimmäiseen topiciin

13. heinäkuuta 2026Päivitetty 22. marraskuuta 2026Abra Robotics
Lyhyesti: Unitree-robotit viestivät DDS:n kautta, samalla väliohjelmistolla kuin ROS 2. Virallisella unitree_ros2-paketilla, ROS 2 Humblella Ubuntu 22.04:ssä ja CycloneDDS:llä robotin viesteistä tulee ROS 2 -topicseja ilman siltaa. Tarvitset robotin EDU-version, Ethernet-kaapelin ja tietokoneen aliverkossa 192.168.123.x.

ROS 2 Unitree-roboteissa toimii ilman takaisinmallinnusta ja ilman käännössolmuja: robotti julkaisee tietonsa DDS:n (CycloneDDS) kautta, ja ROS 2 käyttää DDS:ää viestintäkerroksena. Virallinen unitree_ros2-paketti sisältää viestimääritykset ja asetusskriptit. Alla olevat vaiheet noudattavat virallista README-tiedostoa.

Mitkä Unitree-robotit tukevat ROS 2:ta

Ohjelmistokehitys on mahdollista vain kehittäjäversioissa. Go2:n virallinen esite mainitsee SDK-pääsyn omaan kehitykseen EDU-versiossa, ei Airissa eikä Prossa; G1:llä sama koskee G1 EDU:ta.

Mitä tarvitset

  • robotin EDU-versiona (Go2 EDU, G1 EDU, B2, H2);
  • tietokoneen, jossa on Ubuntu 22.04 ja ROS 2 Humble, Unitreen suosittelema yhdistelmä (ROS 2 Humble asennetaan virallisen ohjeen mukaan);
  • Ethernet-kaapelin tietokoneen ja robotin välille.

unitree_ros2:n asennus

1. Lataa repositorio ja asenna riippuvuudet:

git clone https://github.com/unitreerobotics/unitree_ros2
sudo apt install ros-humble-rmw-cyclonedds-cpp ros-humble-rosidl-generator-dds-idl libyaml-cpp-dev

2. Käännä viestipaketit:

cd ~/unitree_ros2/cyclonedds_ws
source /opt/ros/humble/setup.bash
colcon build

Verkko ja CycloneDDS

Liitä tietokone robottiin Ethernet-kaapelilla. Aseta liitännän asetuksissa IPv4 käsin, osoite 192.168.123.99, aliverkon peite 255.255.255.0, kuten README neuvoo. Selvitä liitännän nimi komennolla ifconfig tai ip a (esimerkiksi enp3s0) ja kirjoita se tiedostoon ~/unitree_ros2/setup.sh:

#!/bin/bash
source /opt/ros/humble/setup.bash
source $HOME/unitree_ros2/cyclonedds_ws/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces>
  <NetworkInterface name="enp3s0" priority="default" multicast="default" />
</Interfaces></General></Domain></CycloneDDS>'

Ratkaiseva rivi on RMW_IMPLEMENTATION=rmw_cyclonedds_cpp: Humblen oletusväliohjelmisto on eri, ja ilman tätä muuttujaa tietokone ei näe robottia. ROS 2 -dokumentaatio kertoo, miten DDS-väliohjelmisto valitaan. Ilman liitettyä robottia voit käyttää setup_local.sh-skriptiä, joka toimii loopback-liitännässä.

Ensimmäinen topic

source ~/unitree_ros2/setup.sh
ros2 topic list
ros2 topic echo /sportmodestate

Go2:ssa ja B2:ssa /sportmodestate kertoo sijainnin, nopeuden ja askellajin; /lowstate kertoo moottorit, IMU:n ja akun. Esimerkkien kääntäminen ja ajaminen:

cd ~/unitree_ros2/example
colcon build
./install/unitree_ros2_example/bin/read_motion_state

README näyttää myös, miten Go2:n LiDARin pistepilvi näytetään RViz2:ssa topicissa utlidar/cloud kehyksellä utlidar_lidar.

Ohjaus: korkea ja matala taso

  • Korkea taso (Go2, B2): pyynnöt topiciin /api/sport/request unitree_api-viesteillä, jotka esimerkkien SportClient-luokka luo. Robotti käyttää omaa liikeohjaustaan.
  • Matala taso: sijainti-, nopeus-, momentti- ja vahvistuskomennot topiciin /lowcmd. Ensin sisäänrakennettu liikepalvelu on poistettava käytöstä, muuten komennot menevät päällekkäin. Humanoideissa siirrytään debug-tilaan L2+R2:lla robotin roikkuessa: koko menettely on oppaassa G1:n ohjelmointi.

Simuloi ennen laitteistoa

unitree_mujoco on MuJoCoon perustuva virallinen simulaattori: se hyväksyy ohjelmat, jotka on kirjoitettu unitree_sdk2:lla, unitree_sdk2_python:lla ja unitree_ros2:lla, samoilla matalan tason viesteillä kuin oikea robotti. Kehitys tehdään simulaatiossa loopback-liitännässä, minkä jälkeen sama koodi toimii robotissa, ja vain verkkoliitäntä vaihtuu. Kävely-policyjä varten on unitree_rl_gym (Go2, G1, H1, H1-2).

Yleiset virheet

  • Ei topiceja: RMW asettamatta, väärä liitäntä tiedostossa setup.sh tai tietokone aliverkon ulkopuolella. README suosittelee myös tietokoneen uudelleenkäynnistystä ensimmäisen määrityksen jälkeen.
  • Useita ROS-asennuksia samassa tietokoneessa: älä lisää setup.sh:ta tiedostoon ~/.bashrc, vaan lataa se käsin tarvittaessa.

Usein kysyttyä

Mitä ROS 2 -versiota Unitree-roboteissa kannattaa käyttää?

Humblea Ubuntu 22.04:ssä: se on Unitreen suosittelema yhdistelmä.

Voiko Go2 Airia tai Prota käyttää ROS 2:n kanssa?

Ei. SDK ja siten ROS 2 on vain Go2 EDU:ssa.

Tarvitaanko SDK:n ja ROS 2:n välille silta?

Ei. Robotti ja ROS 2 puhuvat molemmat DDS:ää: unitree_ros2:n ja CycloneDDS:n avulla robotin viestit ovat jo ROS 2 -topiceja.

Miksi ros2 topic list ei näytä robotin topiceja?

Yleensä puuttuu RMW_IMPLEMENTATION=rmw_cyclonedds_cpp, liitäntä setup.sh:ssa on väärä tai tietokone ei ole aliverkossa 192.168.123.x. Ping robottiin selvittää kolmannen tapauksen.

Voiko ROS 2:ta käyttää ilman liitettyä robottia?

Kyllä, setup_local.sh:lla loopback-liitännässä ja unitree_mujoco-simulaattorilla, joka käyttää samoja viestejä kuin robotti.
