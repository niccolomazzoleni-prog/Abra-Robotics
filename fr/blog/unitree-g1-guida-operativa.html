Unitree G1 · Guide d'utilisation

Unitree G1 : mettre en marche, utiliser la télécommande et connecter le PC

Mis à jour le 15 octobre 2026Abra Robotics~20 min

Guide d'utilisation de l'Unitree G1 EDU : variantes, mise en marche, commandes de la télécommande R3, batterie, réseau et SSH. Les commandes suivent l'autocollant officiel de la télécommande et la documentation développeurs Unitree. Pour la programmation avec le SDK et ROS 2, voir l'article dédié.

Protection physique du robot

Protections conseillées : sur un sol dur, le G1 se marque vite, surtout lors de démos avec beaucoup de mouvements au sol. Nous conseillons des protections souples (par exemple en néoprène) sur les bras et les jambes et, au premier démarrage, le cadre de protection proposé au tarif. La méthode « depuis le sol » (L2+X) augmente le risque de marques sur les coudes et les genoux.

Télécommande R3

Mise en marche : pression courte sur le bouton power, puis maintenir ≥2 s (deux bips). Arrêt : pression courte puis longue ≥2 s (trois bips).

Batterie de la télécommande : elle peut se décharger avant les batteries du G1. Gardez la télécommande chargée : sans la R3, vous ne contrôlez pas le robot en sécurité.

Télécommande incluse ou disponible séparément : G1 Remote Controller.

Commandes de la télécommande (firmware actuel)

Les combinaisons peuvent changer avec la version du firmware : vérifiez toujours l'autocollant de votre télécommande avant d'utiliser le robot.

Légende des commandes imprimée sur la télécommande R3 :

  • ★ = pression courte unique
  • ▲ = pression longue d'environ 2 secondes (en motion control, maintenir le damping L2 + B pendant 5 secondes active la protection damping, comme l'indique l'autocollant)

Adapt riseR1 + R2 + X★
Sécurité : pour arrêter le robot, utilisez le damping, L2 + B (en motion control, maintenez-le 5 secondes pour la protection damping). Ne le confondez pas avec L2 + Y (zero moment) : cette commande annule le couple des moteurs et, si le robot n'est pas suspendu au harnais ou au cadre, il tombe.

Salutations et gestes (handshake, wave, kiss, clap) : utilisez-les en Regular mode, avec R1 + Y si la taille a 3 DoF (U2+) ou R1 + X si elle a 1 DoF (U1). En Running mode (R2+A), le robot est moins stable : une poignée de main ou un salut peut le déséquilibrer. Commandes interactives : SELECT + A (poignée de main), SELECT + Y (salut), double clic Y/X/A (voir l'autocollant).

Debug mode (développement SDK uniquement)

L2 + R2 arrête le motion controller pour éviter les conflits avec le SDK ; L2 + A permet de vérifier que le robot est bien en debug mode (source : Unitree, remote control). Ce mode ne sert qu'en laboratoire, quand vous programmez les moteurs à bas niveau. Pour un usage normal à la télécommande, n'entrez pas en debug : redémarrez le G1 pour en sortir.

Séquences de mise en marche conseillées (selon l'autocollant)

  • Depuis la position assise (conseillée) : mise en marche, puis (1) Damping, (2) Locked standing, (3) Running/Regular, démo, (4) Assis, arrêt. Étapes (2) et (3) avec une personne qui soutient le robot aux épaules.
  • Depuis la position allongée : mise en marche, puis (1), (10), démo, (6), arrêt.
  • Depuis le squat : mise en marche, puis (1), (6), démo, (6), arrêt.

Mise en marche de la batterie du G1

  1. Insérez la batterie jusqu'au clic (interrupteur tourné vers l'arrière).
  2. Pression courte sur le bouton, puis maintenez ≥2 s.
  3. Attendez environ 1 min : toutes les articulations sont en zero torque.
  4. Suivez la séquence de la télécommande ci-dessus : d'abord le damping (L2 + B), puis continuez.

Méthode suspendue au cadre (laboratoire)

Conseillée au premier démarrage : cadre de protection. Suspendez le robot et ne posez les pieds au sol qu'après stabilisation en Regular mode. Bras et jambes libres, aucun câble tendu.

Méthode depuis le sol (L2+X)

Uniquement sur une surface plane et dure. Le robot se relève seul : restez à distance. Avec des manipulateurs (U3 à U10), évitez cette méthode. Utilisez des protections en néoprène : sur le béton, le mouvement marque tout de suite le plastique et l'aluminium.

Charge utile et bras

Unitree annonce une charge maximale par bras d'environ 3 kg sur le G1 EDU (environ 2 kg sur le G1 de base) et précise qu'elle varie beaucoup selon la posture du bras (fiche G1). En pratique, bras tendu, même 1 kg peut déséquilibrer le robot vers l'avant et perturber la marche. Pour les salutations et les gestes, ne chargez pas les bras.

Batterie et autonomie

Selon Unitree, le G1 est équipé d'une batterie intelligente à remplacement rapide de 9000 mAh, pour environ 2 heures d'autonomie. La valeur réelle baisse en cas de marche continue et de charges sur les bras.

  • Pour une journée d'essais, il faut au moins deux batteries : la batterie supplémentaire G1 est au tarif à 880 €, le chargeur à 147 € (HT).
  • Éteignez le robot avant de changer la batterie et remettez-le en damping avant de le faire se relever.
  • Gardez aussi la télécommande R3 chargée : sans elle, vous n'avez pas de moyen rapide d'arrêter le robot.

Réseau et SSH

Placez le PC sur le sous-réseau 192.168.123.0/24 avec une IP statique libre (par ex. .51 ; n'utilisez pas .161, .164, .120). Le PC1 (.161) exécute le contrôle de mouvement Unitree et n'est pas ouvert aux développeurs ; le développement se fait sur le PC2 (.164).

  • Ethernet direct sur le port LAN du G1
  • Wi‑Fi : d'après la documentation LeRobot, le Wi‑Fi du PC2 est désactivé par défaut et doit être activé à la main ; pour installer des paquets, vous pouvez partager la connexion du PC via Ethernet.

Identifiants : unitree / 123 sont les identifiants par défaut, également indiqués dans la documentation LeRobot. Unitree demande de s'adresser au support pour obtenir les identifiants initiaux : ils peuvent donc différer sur certaines unités. Après la première connexion, changez le mot de passe, surtout si le robot rejoint le réseau de l'entreprise.

H2 : il utilise le même sous-réseau 192.168.123.x, avec un PC1 pour le contrôle (Intel Core i5) et un PC2 pour le développement (Intel Core i7 sur la version EDU, selon la fiche Unitree). Les adresses exactes dépendent de la configuration : vérifiez-les dans la documentation de livraison.

Problèmes fréquents

  • Le ping ne répond pas : vérifiez le câble Ethernet et l'IP du PC, puis redémarrez le robot.
  • SSH ne se connecte pas ou est lent : trop de sessions SSH ouvertes ou Jetson saturé ; redémarrez le G1.
  • Le SDK fait trembler les articulations : motion controller actif en parallèle, ou double commande (télécommande et SDK en même temps). Entrez en debug mode uniquement pour le développement, ou arrêtez les commandes SDK.

Questions fréquentes

G1-U1 ou G1-U2 ?

U1 = 23 DoF, taille 1 DoF. U2 = 29 DoF, taille 3 DoF et bras 7 DoF : c'est la base pour la manipulation.

Quel mode de marche pour les salutations ?

R1+Y (taille 3 DoF, U2+) ou R1+X (taille 1 DoF, U1) en Regular mode, pas R2+A en Running mode.

Quel est le mot de passe SSH ?

Par défaut unitree / 123 sur 192.168.123.164 (PC2). Sur certaines unités, ils peuvent être différents : Unitree les fournit via son support. Changez-les après la première connexion.

Comment arrêter le G1 en sécurité ?

Avec le damping, L2 + B. N'utilisez pas L2 + Y (zero moment) : cette commande annule le couple et le robot tombe s'il n'est pas suspendu.

Quelle est l'autonomie de la batterie du G1 ?

Environ 2 heures selon Unitree, avec la batterie de 9000 mAh. Pour une journée d'essais, il faut au moins deux batteries.

Le G1 Air se connecte-t-il en SSH comme l'EDU ?

Non. Le développement secondaire n'est prévu que sur le G1 EDU, qui dispose du PC2 pour le code utilisateur.
