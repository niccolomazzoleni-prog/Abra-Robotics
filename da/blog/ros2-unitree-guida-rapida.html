ROS 2 på Unitree-robotter: fra nul til første topic

13. juli 2026Opdateret 22. november 2026Abra Robotics
Kort sagt: Unitree-robotter kommunikerer via DDS, samme middleware som ROS 2. Med den officielle pakke unitree_ros2, ROS 2 Humble på Ubuntu 22.04 og CycloneDDS bliver robottens beskeder til ROS 2-topics uden bridge. Du skal bruge en EDU-version af robotten, et Ethernetkabel og pc'en på subnettet 192.168.123.x.

ROS 2 på Unitree-robotter virker uden reverse engineering og uden oversættelsesnoder: robotten publicerer sine data via DDS (CycloneDDS), og ROS 2 bruger DDS som kommunikationslag. Den officielle pakke unitree_ros2 indeholder beskeddefinitionerne og konfigurationsscripts. Trinnene nedenfor følger den officielle README.

Hvilke Unitree-robotter understøtter ROS 2

Softwareudvikling er kun mulig på udviklerversionerne. For Go2 angiver det officielle datablad SDK-adgang til egen udvikling på EDU-versionen, ikke på Air og Pro; for G1 gælder det samme med G1 EDU.

RobotBeskeder i unitree_ros2ROS 2-eksempler i repoet
Go2 EDUunitree_gosport client, stand, robotstatus, lavt niveau
B2 / B2Wunitree_gosport client, stand
G1 EDUunitree_hgg1_low_level_example
H2unitree_hgh2_loco_client (højt niveau), h2_ankle_swing_example (lavt niveau)
H1 / H1-2unitree_go / unitree_hglavt niveau H1-2

For R1 og A2 indeholder unitree_sdk2 i oktober 2026 egne C++-eksempler, men unitree_ros2 har endnu ingen specifikke eksempler. Kontrollér repoets status, før du køber til et projekt, der kun bruger ROS 2 på disse modeller.

Det skal du bruge

  • en robot i EDU-version (Go2 EDU, G1 EDU, B2, H2);
  • en pc med Ubuntu 22.04 og ROS 2 Humble, den kombination Unitree anbefaler (ROS 2 Humble installeres efter den officielle vejledning);
  • et Ethernetkabel mellem pc og robot.

Installér unitree_ros2

1. Download repoet, og installér afhængighederne:

git clone https://github.com/unitreerobotics/unitree_ros2
sudo apt install ros-humble-rmw-cyclonedds-cpp ros-humble-rosidl-generator-dds-idl libyaml-cpp-dev

2. Kompilér beskedpakkerne:

cd ~/unitree_ros2/cyclonedds_ws
source /opt/ros/humble/setup.bash
colcon build

Netværk og CycloneDDS

Forbind pc'en med robotten med et Ethernetkabel. Indstil IPv4 manuelt i grænsefladens indstillinger, adresse 192.168.123.99, netmaske 255.255.255.0, som README angiver. Find grænsefladens navn med ifconfig eller ip a (for eksempel enp3s0), og skriv det i ~/unitree_ros2/setup.sh:

#!/bin/bash
source /opt/ros/humble/setup.bash
source $HOME/unitree_ros2/cyclonedds_ws/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces>
  <NetworkInterface name="enp3s0" priority="default" multicast="default" />
</Interfaces></General></Domain></CycloneDDS>'

Den afgørende linje er RMW_IMPLEMENTATION=rmw_cyclonedds_cpp: Humbles standard-middleware er en anden, og uden denne variabel kan pc'en ikke se robotten. ROS 2-dokumentationen forklarer, hvordan man vælger DDS-middleware. Uden tilsluttet robot kan du bruge setup_local.sh, der arbejder på loopback-grænsefladen.

Første topic

source ~/unitree_ros2/setup.sh
ros2 topic list
ros2 topic echo /sportmodestate

På Go2 og B2 giver /sportmodestate position, hastighed og gangart; /lowstate giver motorer, IMU og batteri. Kompilér og kør eksemplerne:

cd ~/unitree_ros2/example
colcon build
./install/unitree_ros2_example/bin/read_motion_state

README viser også, hvordan man viser punktskyen fra Go2's LiDAR i RViz2, på topic utlidar/cloud med rammen utlidar_lidar.

Styring: højt og lavt niveau

  • Højt niveau (Go2, B2): forespørgsler på /api/sport/request med unitree_api-beskeder, som oprettes af klassen SportClient i eksemplerne. Robotten bruger sin egen bevægelsesstyring.
  • Lavt niveau: kommandoer for position, hastighed, moment og forstærkninger på /lowcmd. Først skal den indbyggede bevægelsestjeneste slås fra, ellers overlapper kommandoerne. På humanoider går man i debug-tilstand med L2+R2, med robotten hængende: hele proceduren står i guiden programmér G1.

Simulér før hardwaren

unitree_mujoco er den officielle simulator baseret på MuJoCo: den tager imod programmer skrevet med unitree_sdk2, unitree_sdk2_python og unitree_ros2, med de samme lavniveaubeskeder som den rigtige robot. Man udvikler i simuleringen på loopback-grænsefladen, derefter kører den samme kode på robotten, og kun netværksgrænsefladen ændres. Til gang-policies findes unitree_rl_gym (Go2, G1, H1, H1-2).

Almindelige fejl

  • Ingen topics: RMW ikke sat, forkert grænseflade i setup.sh eller pc uden for subnettet. README anbefaler også at genstarte pc'en efter første konfiguration.
  • Flere ROS-installationer på samme pc: læg ikke setup.sh i ~/.bashrc, men indlæs den manuelt, når den skal bruges.

Ofte stillede spørgsmål

Hvilken version af ROS 2 skal man bruge med Unitree-robotter?

Humble på Ubuntu 22.04: det er den kombination, Unitree anbefaler.

Kan Go2 Air eller Pro bruges med ROS 2?

Nej. SDK, og dermed ROS 2, findes kun på Go2 EDU.

Skal man installere en bridge mellem SDK og ROS 2?

Nej. Robotten og ROS 2 taler begge DDS: med unitree_ros2 og CycloneDDS er robottens beskeder allerede ROS 2-topics.

Hvorfor viser ros2 topic list ikke robottens topics?

Oftest mangler RMW_IMPLEMENTATION=rmw_cyclonedds_cpp, grænsefladen i setup.sh er forkert, eller pc'en er ikke på subnettet 192.168.123.x. Et ping til robotten afklarer det tredje tilfælde.

Kan man bruge ROS 2 uden tilsluttet robot?

Ja, med setup_local.sh på loopback-grænsefladen og med simulatoren unitree_mujoco, der bruger de samme beskeder som robotten.
