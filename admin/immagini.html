Gestione immagini prodotto

Importa un'immagine per SKU, aggiorna il percorso o incolla un URL Unitree. Salva nella cartella del progetto (Chrome/Edge) oppure esporta uno ZIP e lancia python scripts/publish_images.py --from-zip export.zip.

Dopo le modifiche, da terminale nella root del progetto:
python scripts/publish_images.py
oppure con ZIP: python scripts/publish_images.py --from-zip percorso/export.zip
