Come modificare

  1. Modifica i file .md sotto (o su GitHub con «Modifica su GitHub»).
  2. Al push su main, GitHub Actions rigenera knowledge-index.json (~1 min).
  3. In locale: python scripts/build_knowledge_index.py poi commit del JSON.
  4. Usa «Test ricerca» sotto per verificare che la chat trovi i nuovi contenuti.

Feedback dalla chat → Admin Offerte AI → «Esporta KB markdown» → merge con scripts/merge_feedback_to_kb.py.
