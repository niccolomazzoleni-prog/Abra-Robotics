Unitree G1 · Operating guide

Unitree G1: how to switch on, use the remote and connect the PC

Updated 22 November 2026Abra Robotics~20 min

Operating guide for the Unitree G1 EDU: variants, switching on, R3 remote commands, battery, network and SSH. The commands follow the Unitree documentation updated to November 2026: they change with the firmware, so always compare them with the sticker for your version.

Physical protection of the robot

Recommended covers: for demos with movements on the ground, protect arms and legs with soft covers, for example neoprene. On first start-up use the protective frame from the price list.

R3 remote

The G1 is controlled with the Unitree R3 remote. Unitree states a 780 mAh battery for about 5 hours of use. To switch it on: short press on the power button, then a long press of over 2 seconds until the beep.

Always keep it charged. The remote charges slowly: put it on charge at the end of the day, not just before using the robot. Without the remote there is no quick way to command the robot.

The spare remote is on the price list: G1 Remote Controller, €367 excl. VAT.

Remote commands

Unitree changes the key combinations with firmware versions. The Document Center has a different sticker for each motion control version (8.2, 8.4.2, 8.5, over 8.6) and, in recent versions, for G1 with 23 or 29 degrees of freedom. Before using the robot, check the version in the app and compare the commands with the right sticker on the official remote page. The table below lists the commands from the Unitree documentation updated to November 2026.

Damping and zero torque make the robot fall. L2 + B (damping) and L2 + Y (zero torque) remove active control from the motors: a G1 standing and unsupported loses its balance and falls. Unitree lists L2 + B as the emergency stop for this very reason: use it only when the robot is out of control, or when it is already seated or hanging from the frame.

Gestures: SELECT + Y wave, SELECT + A handshake, SELECT + X turns and waves. Unitree warns that the current walking mode is not designed for stairs.

Switch-on and switch-off sequences

  • Seated on a chair (the simplest): switch on → ① damping → ② locked standing, holding the robot by the shoulders → ③ or ⑦ → use → in front of the chair ④ seated → ① damping → switch off.
  • Hanging from the protective frame: switch on and wait about a minute and a half → ① damping → ② → lower the hook until the feet touch the ground → R2 + A → when it walks stably, release the hook. To switch off: hook the robot again, then ① damping and switch off.
  • From lying or crouched: only on a flat, hard floor. With the robotic hands fitted, Unitree advises against these starts, because they can damage the hands.

To stop the robot while it walks, release the sticks and switch to standing (double click START). Damping is applied only after the robot is seated or hanging.

Debug mode

It is only for those who develop with the SDK: L2 + R2, from damping or zero torque, stops the Unitree motion program so it does not conflict with the SDK commands. In debug mode the robot no longer responds to normal motion commands. To exit debug mode, restart the robot. The case is discussed in issue #43 of unitree_sdk2_python.

Battery: insertion and switch-on

  • Insert the battery from the robot's side, the right way round and without forcing, until it clicks.
  • Short press on the battery button, then a long press of at least 2 seconds.
  • Wait about a minute: at the end of start-up the joints are in zero torque and the robot must be seated or hanging.
  • Follow one of the sequences above. On first start-up use the protective frame (€367 excl. VAT).

Arm payload

Unitree states a maximum payload per arm of about 3 kg on the G1 EDU (about 2 kg on the base G1) and specifies that it varies greatly with the arm posture.

Battery and battery life

The G1 has a 9000 mAh quick-release battery: Unitree states about 2 hours of battery life, which drops with continuous walking and loads on the arms.

  • For a day of tests you need at least two batteries: G1 battery €880 excl. VAT, charger €147 excl. VAT.
  • Before changing the battery, put the robot seated or hanging, then damping and switch off.

Network and SSH (G1 EDU only)

Put the PC on the 192.168.123.0/24 network with a free static IP, for example 192.168.123.99. Do not use the robot's addresses:

AddressWhat is there
192.168.123.161PC1, Unitree motion control: not accessible
192.168.123.164PC2 (Jetson Orin), the development computer
192.168.123.120Livox MID-360 LiDAR, if fitted
ping 192.168.123.164
ssh unitree@192.168.123.164
# user: unitree   password: 123

Default PC2 credentials: user unitree, password 123. Change the password at first login, especially if the robot joins the company network.

The recommended connection is a direct Ethernet cable to the robot's port.

If something goes wrong

  • The ping does not answer: check the cable and the PC's IP, then restart the robot.
  • With the SDK the robot shakes: the Unitree motion program and the SDK send commands at the same time. Enter debug mode, or stop the SDK commands.
  • The robot is not stable or does not balance: see the guide to common G1 problems.

FAQ

G1-U1 or G1-U2?

The U1 is enough for locomotion and control. The U2 adds a 3-axis waist and 7-axis arms: you need it if the project involves manipulation.

What are the G1 SSH credentials?

On PC2 (192.168.123.164) user unitree, password 123. Change the password at first login.

How do I stop the G1 safely?

While it walks: release the sticks and switch to standing with a double click on START, then make it sit in front of a chair or hook it back onto the frame. Damping (L2 + B) and zero torque (L2 + Y) make a standing robot fall: use damping only as an emergency stop or when seated/hanging.

Are the remote commands always the same?

No, Unitree changes them with firmware versions. Check the version in the app and the matching sticker in the Unitree Document Center.

How long does the G1 battery last?

About 2 hours according to Unitree. For a day of tests you need at least two batteries.

Does the G1 Air connect via SSH like the EDU?

No. PC2 for user code and SDK development is only on the G1 EDU.
