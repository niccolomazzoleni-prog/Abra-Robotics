ROS 2 på Unitree-roboter: fra null til første topic

13. juli 2026Oppdatert 22. november 2026Abra Robotics
Kort fortalt: Unitree-roboter kommuniserer via DDS, samme mellomvare som ROS 2. Med den offisielle pakken unitree_ros2, ROS 2 Humble på Ubuntu 22.04 og CycloneDDS blir robotens meldinger ROS 2-topics uten bro. Du trenger en EDU-versjon av roboten, en Ethernet-kabel og PC-en i subnettet 192.168.123.x.

ROS 2 på Unitree-roboter fungerer uten omvendt utvikling og uten oversettelsesnoder: roboten publiserer dataene sine via DDS (CycloneDDS), og ROS 2 bruker DDS som kommunikasjonslag. Den offisielle pakken unitree_ros2 inneholder meldingsdefinisjonene og konfigurasjonsskriptene. Stegene nedenfor følger den offisielle README-filen.

Hvilke Unitree-roboter som støtter ROS 2

Programvareutvikling er bare mulig på utviklerversjonene. For Go2 oppgir det offisielle databladet SDK-tilgang for egen utvikling på EDU-versjonen, ikke på Air og Pro; for G1 gjelder det samme med G1 EDU.

Dette trenger du

  • en robot i EDU-versjon (Go2 EDU, G1 EDU, B2, H2);
  • en PC med Ubuntu 22.04 og ROS 2 Humble, kombinasjonen Unitree anbefaler (ROS 2 Humble installeres etter den offisielle veiledningen);
  • en Ethernet-kabel mellom PC og robot.

Installer unitree_ros2

1. Last ned repoet og installer avhengighetene:

git clone https://github.com/unitreerobotics/unitree_ros2
sudo apt install ros-humble-rmw-cyclonedds-cpp ros-humble-rosidl-generator-dds-idl libyaml-cpp-dev

2. Kompiler meldingspakkene:

cd ~/unitree_ros2/cyclonedds_ws
source /opt/ros/humble/setup.bash
colcon build

Nettverk og CycloneDDS

Koble PC-en til roboten med en Ethernet-kabel. Still inn IPv4 manuelt i grensesnittets innstillinger, adresse 192.168.123.99, nettmaske 255.255.255.0, slik README-filen sier. Finn navnet på grensesnittet med ifconfig eller ip a (for eksempel enp3s0) og skriv det inn i ~/unitree_ros2/setup.sh:

#!/bin/bash
source /opt/ros/humble/setup.bash
source $HOME/unitree_ros2/cyclonedds_ws/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces>
  <NetworkInterface name="enp3s0" priority="default" multicast="default" />
</Interfaces></General></Domain></CycloneDDS>'

Den avgjørende linjen er RMW_IMPLEMENTATION=rmw_cyclonedds_cpp: standard mellomvare i Humble er en annen, og uten denne variabelen ser ikke PC-en roboten. ROS 2-dokumentasjonen forklarer hvordan man velger DDS-mellomvare. Uten tilkoblet robot kan du bruke setup_local.sh, som arbeider på loopback-grensesnittet.

Første topic

source ~/unitree_ros2/setup.sh
ros2 topic list
ros2 topic echo /sportmodestate

På Go2 og B2 gir /sportmodestate posisjon, hastighet og gangart; /lowstate gir motorer, IMU og batteri. Kompiler og kjør eksemplene:

cd ~/unitree_ros2/example
colcon build
./install/unitree_ros2_example/bin/read_motion_state

README-filen viser også hvordan man viser punktskyen fra LiDAR-en på Go2 i RViz2, på topic utlidar/cloud med rammen utlidar_lidar.

Styring: høyt og lavt nivå

  • Høyt nivå (Go2, B2): forespørsler på /api/sport/request med unitree_api-meldinger, som lages av klassen SportClient i eksemplene. Roboten bruker sin egen bevegelsesstyring.
  • Lavt nivå: kommandoer for posisjon, hastighet, moment og forsterkninger på /lowcmd. Først må den innebygde bevegelsestjenesten slås av, ellers overlapper kommandoene. På humanoider går man til feilsøkingsmodus med L2+R2, med roboten hengende: hele prosedyren står i guiden programmere G1.

Simuler før maskinvaren

unitree_mujoco er den offisielle simulatoren basert på MuJoCo: den tar imot programmer skrevet med unitree_sdk2, unitree_sdk2_python og unitree_ros2, med de samme lavnivåmeldingene som den ekte roboten. Man utvikler i simuleringen på loopback-grensesnittet, deretter kjører den samme koden på roboten, og bare nettverksgrensesnittet endres. For gange-policies finnes unitree_rl_gym (Go2, G1, H1, H1-2).

Vanlige feil

  • Ingen topics: RMW ikke satt, feil grensesnitt i setup.sh eller PC utenfor subnettet. README-filen anbefaler også å starte PC-en på nytt etter første konfigurasjon.
  • Flere ROS-installasjoner på samme PC: ikke legg setup.sh i ~/.bashrc, men last den manuelt når du trenger den.

Vanlige spørsmål

Hvilken versjon av ROS 2 bør man bruke med Unitree-roboter?

Humble på Ubuntu 22.04: det er kombinasjonen Unitree anbefaler.

Kan Go2 Air eller Pro brukes med ROS 2?

Nei. SDK, og dermed ROS 2, finnes bare på Go2 EDU.

Må man installere en bro mellom SDK og ROS 2?

Nei. Roboten og ROS 2 snakker begge DDS: med unitree_ros2 og CycloneDDS er robotens meldinger allerede ROS 2-topics.

Hvorfor viser ikke ros2 topic list robotens topics?

Oftest mangler RMW_IMPLEMENTATION=rmw_cyclonedds_cpp, grensesnittet i setup.sh er feil, eller PC-en er ikke i subnettet 192.168.123.x. En ping til roboten avklarer det tredje tilfellet.

Kan man bruke ROS 2 uten tilkoblet robot?

Ja, med setup_local.sh på loopback-grensesnittet og med simulatoren unitree_mujoco, som bruker de samme meldingene som roboten.
