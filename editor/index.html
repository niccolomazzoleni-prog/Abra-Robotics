Accedi all'editor

Le modifiche vengono salvate direttamente sul sito tramite GitHub. Serve un token del tuo account GitHub (collaboratore del repository niccolomazzoleni-prog/Abra-Robotics).

  1. Crea il token su GitHub: il permesso public_repo è già selezionato, scegli una scadenza e premi Generate token.
  2. Copia il token (inizia con ghp_) e incollalo qui.

Il token resta solo in questo browser e viene usato solo per parlare con GitHub.
