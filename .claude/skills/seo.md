# SEO Optimization Skill

Comprehensive SEO analysis and implementation for web pages and sites.

## On-Page SEO Checklist

When building or reviewing any page, ensure:

### Title Tag
- Present, 50-60 characters
- Contains primary keyword near the beginning
- Compelling and click-worthy
- Unique per page

### Meta Description
- Present, 150-160 characters
- Contains primary keyword and CTA
- Engaging, action-oriented language
- Unique per page

### Heading Hierarchy
- Single H1 per page containing primary keyword
- H2/H3 logical hierarchy with keyword variants
- No heading level skipping (H1 → H3)
- Headings describe content sections accurately

### URL Structure
- Clean, readable, keyword-containing URLs
- No excessive parameters or stop words
- Hyphens between words, lowercase

### Content Quality (E-E-A-T)
- **Experience**: First-hand experience signals, case studies, real examples
- **Expertise**: Author credentials, detailed technical knowledge
- **Authoritativeness**: Brand signals, industry recognition, partnerships
- **Trustworthiness**: Contact info, about page, testimonials, certifications
- Word count: 500+ for standard pages, 1500+ for pillar content
- Primary topic clearly established with semantic related terms
- Content freshness signals (dates, updates)
- Scannable: subheadings, short paragraphs, bullets

### Technical SEO
- Canonical tag present and self-referencing
- Robots meta: indexable (no accidental noindex)
- Viewport meta for mobile friendliness
- HTTPS enabled
- Clean crawlability (no excessive JS-only rendering)
- Fast load times (optimize images, minimize CSS/JS)

### Images
- All images have descriptive, keyword-relevant alt text
- Images compressed and properly sized
- Use modern formats (WebP) where possible
- Lazy loading for below-fold images

### Internal Links
- Descriptive anchor text (not "click here")
- Link to related content within the site
- Logical site architecture

### Structured Data (Schema.org)
- Organization schema with name, logo, URL, social profiles
- Relevant page-type schema (Article, Product, FAQ, HowTo, LocalBusiness)
- JSON-LD format preferred
- Valid and complete markup

### Social Meta
- Open Graph: og:title, og:description, og:image
- Twitter Card meta tags
- Appropriate image dimensions for social sharing

## Keyword Strategy

When optimizing content:
1. Identify primary keyword and 3-5 secondary keywords
2. Use primary keyword in: title, H1, first 100 words, meta description, URL
3. Use secondary keywords naturally in H2s and body content
4. Include long-tail variations and semantic related terms
5. Avoid keyword stuffing — write for humans first

## Priority Levels
- **Critical**: Blocks indexing or causes penalties (immediate fix)
- **High**: Significantly impacts rankings (fix within 1 week)
- **Medium**: Optimization opportunity (fix within 1 month)
- **Low**: Nice to have (backlog)
