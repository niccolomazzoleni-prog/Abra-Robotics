Unitree G1 · Bruksguide

Unitree G1: så startar du roboten, använder fjärrkontrollen och ansluter datorn

Uppdaterad 15 oktober 2026Abra Robotics~20 min

Bruksguide för Unitree G1 EDU: varianter, start, kommandon på fjärrkontrollen R3, batteri, nätverk och SSH. Kommandona följer den officiella dekalen på fjärrkontrollen och Unitrees utvecklardokumentation. Programmering med SDK och ROS 2 tas upp i en separat artikel.

Fysiskt skydd för roboten

Rekommenderade skydd: på hårda golv får G1 snabbt märken, särskilt vid demonstrationer med många rörelser nere vid golvet. Vi rekommenderar mjuka skydd (till exempel i neopren) på armar och ben och, vid första starten, skyddsställningen i prislistan. Metoden ”från golvet” (L2+X) ökar risken för märken på armbågar och knän.

Fjärrkontrollen R3

Påslagning: kort tryck på strömknappen, sedan håll in ≥2 s (två pip). Avstängning: kort tryck + långt tryck ≥2 s (tre pip).

Fjärrkontrollens batteri: det kan ta slut före G1:s batterier. Håll fjärrkontrollen laddad: utan R3 kan du inte styra roboten på ett säkert sätt.

Fjärrkontrollen ingår och kan även köpas separat: G1 Remote Controller.

Kommandon på fjärrkontrollen (aktuell firmware)

Kombinationerna kan ändras med firmwareversionen: kontrollera alltid dekalen på din fjärrkontroll innan du använder roboten.

Teckenförklaring tryckt på fjärrkontrollen R3:

  • ★ = ett enkelt kort tryck
  • ▲ = långt tryck i ~2 sekunder (i motion control går roboten in i dämpningsskyddet om du håller damping L2 + B intryckt i 5 sekunder, enligt dekalen)

Säkerhet: använd damping, L2 + B för att stoppa roboten (i motion control håller du in det i 5 sekunder för dämpningsskyddet). Blanda inte ihop det med L2 + Y (zero moment): det nollställer motorernas vridmoment, och om roboten inte hänger i selen eller ställningen faller den.

Hälsningar och gester (handshake, wave, kiss, clap): använd dem i Regular mode: R1 + Y om du har midja med 3 DoF (U2+) eller R1 + X med midja 1 DoF (U1). I Running mode (R2+A) är roboten mindre stabil: ett handslag eller en hälsning kan få den ur balans. Interaktiva kommandon: SELECT + A (handslag), SELECT + Y (hälsning), dubbelklick Y/X/A (se dekalen).

Debug mode (bara för SDK-utveckling)

L2 + R2 stoppar motion controllern för att undvika konflikter med SDK:t; med L2 + A kontrollerar du att du är i debug mode (källa: Unitree, remote control). Det behövs bara i labbet när du programmerar motorerna på låg nivå. Vid normal användning med fjärrkontrollen ska du inte gå in i debug mode: starta om G1 för att lämna det.

Rekommenderade startsekvenser (enligt dekalen)

  • Från sittande (rekommenderas): Slå på, sedan (1) Damping, (2) Locked standing, (3) Running/Regular, demo, (4) Sittande, stäng av. Vid steg (2) och (3) stöttar en person roboten vid axlarna.
  • Från liggande: Slå på, sedan (1), (10), demo, (6), stäng av.
  • Från squat: Slå på, sedan (1), (6), demo, (6), stäng av.

Starta G1 med batteriet

  1. Sätt i batteriet tills det klickar (strömbrytaren mot baksidan).
  2. Kort tryck på knappen, håll sedan in ≥2 s.
  3. Vänta ~1 min: alla leder är i zero torque.
  4. Följ fjärrkontrollens sekvens ovan: först damping (L2 + B), sedan fortsätter du.

Upphängd i ställningen (labb)

Rekommenderas vid första starten: skyddsställningen. Häng upp roboten och låt fötterna nå golvet först när den har stabiliserats i Regular mode. Armar och ben ska vara fria och inga kablar får vara sträckta.

Från golvet (L2+X)

Bara på en plan och hård yta. Roboten reser sig själv: håll avstånd. Med manipulatorer (U3–U10) ska du undvika den här metoden. Använd neoprenskydd: rörelser på betong ger direkt märken i plast och aluminium.

Last och armar

Unitree anger en maximal last per arm på cirka 3 kg för G1 EDU (cirka 2 kg för bas-G1) och påpekar att den varierar mycket med armens position (produktblad G1). I praktiken kan även 1 kg med utsträckt arm få roboten att tippa framåt och störa gången. Belasta inte armarna vid hälsningar och gester.

Batteri och drifttid

Enligt Unitree har G1 ett smart, snabbutbytbart batteri på 9000 mAh för cirka 2 timmars drifttid. Den verkliga drifttiden blir kortare vid kontinuerlig gång och last på armarna.

  • För en hel testdag behövs minst två batterier: extrabatteriet till G1 kostar 880 € i prislistan och laddaren 147 € (exklusive moms).
  • Stäng av roboten innan du byter batteri och sätt den i damping igen innan du låter den resa sig.
  • Håll också fjärrkontrollen R3 laddad: utan fjärrkontroll har du inget snabbt sätt att stoppa roboten.

Nätverk och SSH

Lägg datorn på subnätet 192.168.123.0/24 med en ledig statisk IP-adress (t.ex. .51; använd inte .161, .164, .120). PC1 (.161) kör Unitrees rörelsestyrning och är inte öppen för utvecklare; utvecklingen sker på PC2 (.164).

  • Direkt Ethernet till G1:s LAN-port
  • Wi‑Fi: enligt LeRobot-dokumentationen är Wi‑Fi avstängt som standard på PC2 och måste aktiveras manuellt; för att installera paket kan du dela datorns uppkoppling via Ethernet.

Inloggningsuppgifter: unitree / 123 är standarduppgifterna, som även anges i LeRobot-dokumentationen. Unitree säger att de initiala uppgifterna ska begäras från supporten, så på vissa enheter kan de vara andra. Byt lösenord efter första inloggningen, särskilt om roboten kopplas in i företagets nätverk.

H2: använder samma subnät 192.168.123.x, med en PC1 för styrningen (Intel Core i5) och en PC2 för utvecklingen (Intel Core i7 på EDU-versionen, enligt Unitrees produktblad). De exakta adresserna beror på konfigurationen: kontrollera dem i leveransdokumentationen.

Vanliga problem

  • Ping svarar inte: kontrollera Ethernetkabeln och datorns IP-adress, och starta sedan om roboten.
  • SSH kommer inte in eller är långsamt: för många SSH-sessioner eller överbelastad Jetson; starta om G1.
  • SDK:t får lederna att skaka: motion controllern är aktiv parallellt, eller så kommer dubbla kommandon (fjärrkontroll och SDK samtidigt). Gå bara in i debug mode för utveckling, eller stoppa SDK-kommandona.

Vanliga frågor

G1-U1 eller G1-U2?

U1 = 23 DoF, midja 1 DoF. U2 = 29 DoF, midja 3 DoF och armar 7 DoF: basen för manipulation.

Vilket walk mode för hälsningar?

R1+Y (midja 3 DoF, U2+) eller R1+X (midja 1 DoF, U1): Regular mode, inte R2+A Running mode.

SSH-lösenord?

Standard är unitree / 123 på 192.168.123.164 (PC2). På vissa enheter kan de vara andra: Unitree lämnar ut dem via supporten. Byt dem efter första inloggningen.

Hur stoppar man G1 på ett säkert sätt?

Med damping, L2 + B. Använd inte L2 + Y (zero moment): det nollställer vridmomentet och roboten faller om den inte hänger upp.

Hur länge räcker batteriet i G1?

Cirka 2 timmar enligt Unitree, med batteriet på 9000 mAh. För en hel testdag behövs minst två batterier.

Går G1 Air att ansluta via SSH som EDU?

Nej. Sekundär utveckling finns bara på G1 EDU, som har PC2 för användarens kod.
